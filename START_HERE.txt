LOCAL STARTUP
1. Unzip the package.
2. Copy your private .env file into the Selly-Bake-House-WebApp-v12.26 folder, if needed for local integrations.
3. Open Terminal.
4. Type cd followed by a space, drag the Selly-Bake-House-WebApp-v12.26 folder into Terminal, and press Return.
5. Run: node server.js
6. Open Chrome or Safari at: http://localhost:3000
